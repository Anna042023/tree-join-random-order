# Experiment record

`short_prefix_medians.csv` contains archived aggregate medians for the 200-vertex and 250-vertex induced-graph prefix experiments. It lists indexed build-plus-prefix times and streaming times for the first 1, 100, and 1,000 outputs.

The source graph edges, raw per-run measurements, and full W1–W4 benchmark inputs are not part of this archive. The JSON fixtures in `../fixtures/` are small synthetic correctness cases.
